# WISE.SpatialData
Specifications, procedures, etc, related to all the WISE Spatial Dataflows

This includes:

* WFD2022 Spatial Data Reporting - https://rod.eionet.europa.eu/obligations/780 *and the RN3 dataflows that will replace them*
* WISE-5 Spatial Data Reporting - https://rod.eionet.europa.eu/obligations/806 *and the RN3 dataflows that will replace them*
* Bathing Water Directive - Identification of Bathing Waters - https://rod.eionet.europa.eu/obligations/788

Master tickets:

* Master ticket - WISE Spatial Data Reporting - 2025 - https://taskman.eionet.europa.eu/issues/283037
